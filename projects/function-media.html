PROJECT · 02 / FUNCTION MEDIA

函数图片 / 视频转换
function-media

一组纯前端小工具，做一件有点抽象的事：把图片、视频「翻译」成一堆带颜色的函数，再用这些函数把画面原样画回来。全程在本地浏览器里跑，你的文件不会上传。

已上线 纯前端 Canvas 函数可视化

01核心思路

先把图片按你选的分辨率切成像素网格，每个像素变成一条有自己颜色的函数。关键技巧是用 0 × 根号 把每条函数「锁」在自己的横向区间里——0 乘任何东西都不改变函数值，但根号的定义域会限制这段函数只在指定 x 范围内生效：

y = f(x) + 0*sqrt(x - xmin) + 0*sqrt(xmax - x)

于是成千上万条函数各管各的一小段，叠在同一坐标系里，就拼回了原图。视频不过是把这套流程逐帧跑一遍，再合成回去。

02包含的工具

  • 图片转函数：上传图片 → 选分辨率 → 导出一堆彩色函数，可复制文本。
  • 函数显示器：同一坐标系叠加绘制多行彩色函数，支持根号区间锁定，能直接还原上面导出的结果。
  • 视频转函数：视频 → 图片组 → 函数组 → 图片组 → 视频，逐帧采样再合成；还能把当前帧的函数直接烧进导出的画面右侧。
