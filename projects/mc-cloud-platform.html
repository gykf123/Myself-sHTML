PROJECT · 01 / MC CLOUD PLATFORM

MC 云串流平台
mc-cloud-platform

把原生 Java 版 Minecraft 跑在自己电脑的「虚拟屏」上，然后通过浏览器把画面串流出来——手机、平板、任意设备打开网页就能玩，你的电脑前台还能继续干别的事。

正在开发 MCP Minecraft · Java 版 串流 / 云游戏

01这是什么

简单说，就是把自己的电脑变成一台「云游戏主机」：游戏本体跑在你的机器上，用一个虚拟显示环境承接画面和输入，再把实时画面推到网页端。你不用在游戏机前坐着，浏览器就是屏幕。

因为跑的是原生 Java 版，存档、模组、玩法都跟本机一致，不是功能阉割的网页复刻版。

02解决什么痛点

  • 随地可玩：出门在外用手机 / 平板 / 别人的电脑，打开网页就接上家里的游戏。
  • 前台不耽误：游戏在虚拟屏里跑，你的电脑该办公办公、该看视频看视频。
  • 不吃终端性能：算力全在本机，终端只负责显示画面和回传操作，老设备也能玩。
