PROJECT · 04 / MP3 PIANO

让钢琴替你
把那首歌弹一遍

丢一段 MP3 进去，浏览器在本地听出主旋律，再用合成钢琴弹回来。人声也能弹——乐器演奏人声，听起来往往比原样播放更有意思。乐谱、PDF、钢琴版音频，全都能带走。

已上线 纯前端 Web Audio 乐谱导出

01它做了什么

从音频里找出每条旋律线的音高和时间，交给钢琴声部重演一遍。这不是简单的变速或变调，而是真的把声音「翻译」成一串音符，再重新演奏。

  • 本地听写：MP3 / WAV / M4A / OGG / FLAC 解码后逐帧做频谱与基频检测，转成 MIDI 音符序列。
  • 钢琴演奏：Web Audio 多泛音合成钢琴音色，按检测到的时值和力度弹奏，琴键跟着亮。
  • 乐谱导出：五线谱与钢琴卷帘两种视图，一键导出 PNG 图片；PDF 自动分页，长曲子也不会被截断。
  • 音频导出：离线渲染整段演奏，可导出 WAV；MP3 用开源编码器在浏览器里现编码，无需上传。
  • 尽量不设限：没有账号、没有时长与次数限制，可调灵敏度、量化音阶、最短音符和 BPM。

02怎么做到的

先把音频降到 16 kHz 单声道，再用 1024 点 Hann 窗做 FFT，在 65–1300 Hz 里找谱峰并做抛物线插值，必要时按半频修正八度，得到每一帧的基频；最后合并连续同音高的帧成音符。

audio → 单声道降采样 → FFT 逐帧听音高 → 合并成音符 → 钢琴合成 + 乐谱绘制

量化音阶可以选「不量化 / 大调 / 小调 / 五声音阶」，跑调的哼唱也能被拉回调内。所有计算都在标签页里完成，文件不会离开设备。

03边界与实话

这是单旋律听写，不是 AI 音源分离：人声歌曲会取最明显的那条旋律线，和弦会取其中最突出的音。伴奏复杂、混响重、多人合唱的片段，出来的谱可能需要手动挑一挑。音越干净、越接近单音，结果越准。

MP3 编码需要首次导出时临时加载一个开源编码器；网络不通时会明确提示，改用 WAV 不影响其他功能。超长音频的处理时间取决于设备性能，听起来是「慢」，不是「被限制」。
