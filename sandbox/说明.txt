小小沙盒在线版 · 网页版（FeSui）
==================================

一、直接玩
  浏览器打开 index.html 即可，不需要装任何东西，也不需要账号。
  挖方块、打怪、造房子，进度自动存在这台设备的浏览器里（localStorage）。
  左下摇杆移动，推到底疾跑；拖动画面转视角；右上角 ☰ 里有飞行 / 种子 / 存档 / 重置。
  生存循环：砍树做木板/木棍 → 合成工作台和石镐 → 下洞穴挖铁矿 → 升级铁镐/钻石镐。
  选中食物时按 ✚ 直接吃；树叶会掉苹果，史莱姆和洞穴怪掉生肉，生肉 + 木板可烤熟。
  顶部小图标依次是：背包 / 合成 / 皮肤 / 聊天 / 菜单 / 保存。
  世界种子在 HUD 左上角显示；同一种子会生成同样的地形、洞穴和矿脉。
  昼夜：一整天 8 分钟，HUD 左上角有时钟（☀ 白天 / ☾ 夜晚）。夜里天色和方块都会变暗，
        怪物刷得更勤、上限更高；熬到天亮就安全了。
  目标：菜单 →「目标 / 成就」有 11 条小目标，从第一铲到钻石镐，完成后自动打勾并存档。
  回站点：菜单 →「返回站点首页」；游戏内不显示全站导航球，免得压住右下角的放置键。

二、联机玩（两种）
  首页点「联机玩」，面板里有两页：

  ① 公网中继（跨网络，推荐）
     默认中继：wss://game.fesui.xn--0iv.gay（Cloudflare Workers，开箱能用）
     用法：
       1. 打开游戏 → 点「联机玩」→ 停在「公网中继」页
       2. 点「创建房间」→ 生成 6 位房间码
       3. 把房间码或邀请链接发给朋友，对方填进去点「加入」
     说明：
       - 中继只转发消息，不跑游戏逻辑，也不记日志
       - 房间和方块改动只在内存里，房间空了就清空
       - 房主掉线留宽限时间，凭密钥能认回来；长期不回会自动换房主
       - 联机权限走 supabase 积分；游戏进度仍只存本机 localStorage
       - 房主世界种子会自动同步给访客；皮肤颜色会显示在对方角色身上
       - 顶部聊天图标打开聊天，输入后回车即可发送给同房玩家

  ①-2 想自己搭一套中继（可选）
     代码有两份，协议完全一致，挑一份用：
       relay/         零依赖 Node，node server.js 就能跑，顺手托管游戏本体
       relay-worker/  Cloudflare Workers + Durable Objects（DO 本体）
       relay-pages/   线上这份：Pages Function 路由 + 外部 CNAME 签证书
     线上中继是 Pages 项目，域名 game.fesui.是.gay；换域名见 relay-pages/README.md。

  ② 同一 Wi-Fi（局域网，不经过公网）
     原理：房主自己跑 local-server/，其他人连房主的 IP。
     用法：
       1. 进入 local-server/ 目录
       2. Windows 双击 run.bat；macOS / Linux 执行 ./run.sh
       3. 浏览器打开 http://127.0.0.1:8765
       4. 房主在「同一 Wi-Fi」页点「创建房间」
       5. 对方在同一 Wi-Fi 下访问 http://房主IP:8765 加入
     注意：房主退出房间就关闭，只在局域网内有效。

三、文件说明
  index.html     页面与界面（含联机面板）
  game.js            游戏逻辑（四个联机入口都过了 netGatePass 门禁）
  sandbox-gate.js    联机门禁：登录态 + 积分解锁状态 + UI
  three.min.js   Three.js 库，本地引用，离线可用
  relay/         公网中继服务（Node 版），部署在服务器上，浏览器不需要下载
                 （server.js 本体、自测.mjs 自测脚本、README.md 部署说明）
  relay-worker/  公网中继服务（Cloudflare Workers 版），线上一份就在跑这个
                 （src/index.js 本体、wrangler.toml 部署配置）
  local-server/  局域网开房脚本，适合同一个 Wi-Fi
  说明.txt       本文件

四、存档与种子
  网页版和本地服务版共用一个浏览器的 localStorage，同一台设备上进度是通的。
  菜单里「世界种子 / 导入导出」可以换种子、导出存档文本、导入存档文本。
  存档 v5 会记住：位置、背包、生命饥饿、种子、皮肤、时刻（白天/夜晚）与成就进度。
  换浏览器或清站点数据会丢存档，重要进度记得导出一份文本留底。
  联机时别人的方块改动来自服务器内存，退出房间后不会写进你的存档。
