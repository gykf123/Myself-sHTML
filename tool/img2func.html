图片转函数

纯前端 · 图片不上传

上传一张图片，按分辨率把它采样成一堆带不同颜色的函数：每个彩色像素变成一小段水平函数，用 +0√(x−xmin)+0√(xmax−x) 把定义域锁在自己的 x 区间里。导出的函数可直接粘进「函数显示器」叠加还原。

⬆1 · 选择图片

点击选择图片，或拖到这里 支持 PNG / JPG / WEBP / GIF（取首帧），全程只在你的浏览器里处理，不会上传

⚙2 · 采样设置

当前：40 像素宽

原理：根号下不能为负。+0√(x−xmin) 让 x < xmin 时无定义，+0√(xmax−x) 让 x > xmax 时无定义，乘 0 又不改变函数值——于是每条函数只在自己那一小段画出来，拼成整张图。
